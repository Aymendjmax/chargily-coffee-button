# دليل الاستخدام

## 1) الحصول على رابط الدفع

الزر مجرد صورة، والذي يستقبل المال هو **رابط الدفع** الذي تنشئه من حسابك في شارجيلي. اتبع توثيقهم الرسمي لإنشاء رابط دفع (Payment Link) مناسب لحالة التبرع، ثم انسخ الرابط واستعمله في الأمثلة التالية بدل `رابط_الدفع`.

> المستودع لا يتعامل مع أي مبالغ ولا يحفظ أي بيانات دفع؛ هو أصول بصرية فقط.

## 2) اختيار العبارة والنسخة

| الملف | العبارة | الأبعاد الافتراضية | عرض مقترح |
|---|---|---|---|
| `chargily-coffee-*.svg` | شارجيلي قهوة | 371 × 103 | 240 – 300 |
| `chargily-sarf-*.svg` | شارجيلي شويا صرف | 470 × 103 | 300 – 380 |

العبارتان بنفس الارتفاع تقريباً عند هذين العرضين، فلا يبدو أحدهما أضخم من الآخر إن وضعتهما معاً. و`*` تعني `purple` أو `light` أو `mono` أو `mono-dark`. ولألوان تخصيصية انظر **[CUSTOMIZE.md](CUSTOMIZE.md)**.

## 3) في `README.md` (Markdown)

أبسط صيغة:

```markdown
[![شارجيلي قهوة](assets/support-button.svg)](رابط_الدفع)
```

وللعبارة الثانية غيّر النص البديل (alt) ليطابقها: `[![شارجيلي شويا صرف](assets/support-button.svg)](رابط_الدفع)`.

تتحكم بالحجم عبر HTML:

```html
<a href="رابط_الدفع">
  <img src="assets/support-button.svg" width="240" alt="شارجيلي قهوة">
</a>
```

للتوسيط:

```html
<p align="center">
  <a href="رابط_الدفع"><img src="assets/support-button.svg" width="260" alt="شارجيلي قهوة"></a>
</p>
```

أحجام مقترحة: `200` للفقرات الصغيرة، `240–280` للقسم العلوي من الـ README.

## 4) في ملف GitHub الشخصي (Profile README)

نفس الصيغة، لكن استخدم رابطاً مطلقاً للصورة لأن ملف المستودع الشخصي يُعرض من مكان آخر:

```html
<a href="رابط_الدفع">
  <img src="https://raw.githubusercontent.com/اسم_المستخدم/اسم_المستودع/main/assets/support-button.svg" width="240" alt="شارجيلي قهوة">
</a>
```

## 5) زر Sponsor في أعلى المستودع (`FUNDING.yml`)

GitHub يعرض زر **Sponsor** إذا أضفت الملف `.github/FUNDING.yml`. يمكنك وضع رابط الدفع ضمن المفتاح `custom`:

```yaml
custom: ["رابط_الدفع"]
```

هذا لا يستخدم صورة الزر، لكنه يكمّلها ويظهر في واجهة المستودع نفسها.

## 6) في موقع أو صفحة HTML

```html
<a href="رابط_الدفع" target="_blank" rel="noopener">
  <img src="support-button.svg" width="240" alt="شارجيلي قهوة">
</a>
```

الأضمن أن تنسخ ملف الزر إلى موقعك بدل الاعتماد على رابط خارجي. للمعاينة المحلية افتح [`examples/index.html`](../examples/index.html).

## 7) متى أستعمل PNG؟

استعمل `assets/png/*.png` في الأماكن التي لا تعرض SVG جيداً (بعض بريد الإلكتروني، منشورات اجتماعية، بعض المنصات). الملفات الأربعة بعرض 1200px، فتبقى حادة على الشاشات عالية الدقة.

## 8) اختيار النسخة

| الحالة | النسخة |
|---|---|
| صفحة بيضاء أو داكنة، تريد زراً بارزاً | **البنفسجية** |
| تصميم هادئ تريد أن يندمج مع النص | **الفاتحة** |
| مشروع بهوية أبيض وأسود | **mono** (أو **mono-dark** للصفحات الداكنة) |
| ألوان مشروعك الخاصة | خصّصها من [صفحة المُخصِّص](../builder/index.html) أو سطر الأوامر، انظر [CUSTOMIZE.md](CUSTOMIZE.md) |
